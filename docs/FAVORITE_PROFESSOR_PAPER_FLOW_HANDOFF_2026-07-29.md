# 교수 즐겨찾기 → 공식 논문 → 논문 한입 인계

기준일: 2026-07-29  
상태: 로컬 구현·검증 완료, AI 생성은 환경 키 필요

## 결과

```text
교수 추천/상세에서 별표 저장
→ 교수님 퀘스트의 ‘교수님 논문 고르기’
→ 즐겨찾는 교수 선택
→ 공식 프로필 수집 최근 논문 최대 6건 검색·연도 필터
→ 논문 선택
→ 공식 제목·발행일·출처 자동 입력
→ 학생이 같은 논문의 초록/본문을 직접 붙여넣고 확인
→ 3분 준비 카드 5장 생성
→ 교수·논문 묶음으로 저장, 재저장 시 갱신
```

## 정확성·안전 경계

- 공식 프로필 데이터에는 모든 초록·원문이 없으므로 논문을 고른 것만으로 요약하지 않는다.
- 제목·발행일·출처만 자동 입력한다.
- 붙여넣은 텍스트가 선택 논문의 초록/본문인지 학생이 확인해야 분석 버튼이 열린다.
- 본문을 수정하면 확인 체크가 자동 해제된다.
- 저장된 제목·URL은 새로고침 뒤 즉시 공식으로 표시하지 않는다.
- 서버가 `professorId + paperId` 소속을 다시 확인한 뒤에만 공식 서지 배지를 표시한다.
- 네트워크 실패는 저장된 선택을 보존하고 재시도·다른 논문·직접 입력을 제공한다.
- 공식 목록에서 관계가 사라진 경우에만 해당 선택을 해제한다.
- 학생이 붙여넣은 원문은 localStorage에 저장하지 않는다.
- 즐겨찾기는 현재 브라우저 로컬 저장이며 로그인·기기 간 동기화는 후속 범위다.

## 저장 규칙

- 공식 논문 bundle ID: `paper:{professorId}:{paperId}`
- 카드 slot: `problem`, `method`, `result`, `limitations`, `questions`
- 같은 bundle과 slot은 새 카드를 추가하지 않고 갱신한다.
- 카드 5장은 store의 단일 액션으로 계산해 저장 공간 오류 때 1~4장만 남는 부분 묶음을 방지한다.
- 저장 공간 오류는 성공으로 표시하지 않고 전체 복사와 브라우저 저장 공간 확인을 안내한다.

## 확인된 환경 한계

- 로컬 환경에 `OPENAI_API_KEY`가 없어 실제 AI 카드 생성은 `AI 연결 설정이 필요합니다.`까지 확인했다. 키가 있는 Vercel 환경 또는 승인된 로컬 설정 후 생성 결과·저장 E2E를 한 번 더 확인한다.
- 연결된 인앱 브라우저의 viewport가 1280×720으로 고정되어 390px 실기기 렌더는 이번 검증에서 열지 못했다. CSS에는 700px·420px 분기, 가로 교수 탭, 단일 열 필터와 버튼 폭 규칙을 적용했다.
- 공식 프로필의 각 교수 논문 배열은 최근 최대 6건이다. UI에서 전체 논문이라고 표현하지 않는다.

## 오류 기록과 재발 방지

### 빌드가 10분 동안 대기한 문제

- 증상: `npm.cmd run build`가 출력 없이 제한시간을 초과했다.
- 원인: `next start` 운영 서버가 같은 `.next` 폴더를 사용 중인 상태에서 빌드를 겹쳐 실행했다.
- 해결: 3100 운영 서버를 종료한 뒤 빌드를 단독 실행해 15.5초에 통과했고, 빌드 후 서버를 다시 시작했다.
- 재발 방지 순서: `서버 종료 → typecheck → 테스트 → build → start`.

### PowerShell HTTP 검증 옵션 문제

- 증상: Windows PowerShell에서 `Invoke-WebRequest -SkipHttpErrorCheck` 옵션을 인식하지 못했다.
- 원인: 해당 옵션은 현재 Windows PowerShell 버전에 없다.
- 해결: `try/catch`에서 응답 상태 코드를 읽어 400을 검증했다.
