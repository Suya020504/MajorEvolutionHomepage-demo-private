# 보편 대학생 입력·교수 3관점 추천 인계서

기준일: 2026-07-29

작업 브랜치: `refactor/your-professor-core-v2`

상태: 로컬 구현·자동 검증·데스크톱 실사용 검증 완료, 원격 저장소 미반영

## 1. 목표와 완료 조건

개인 학생 한 명의 전공·관심사에 고정된 입력을 모든 대학생이 사용할 수 있는 구조로 바꾸고, `나의 교수님 — 찾다`가 처음 방문한 학생도 답할 수 있는 선택형 질문으로 단국대학교 교수 3명을 연결하도록 개선했다.

완료 조건은 다음과 같다.

1. 목록에 없는 학과·전공도 직접 입력할 수 있다.
2. 관심 분야는 보편 태그와 직접 입력을 함께 제공하며 최대 3개다.
3. 학교는 아이디어 생성에서 선택 정보다.
4. 단국대학교를 확인한 경우에만 공식 교수 1,051명 연결 API를 실행한다.
5. 교수 결과는 `주제 연결형`, `방법 연결형`, `확장 관점형` 한 명씩 총 3명이다.
6. 점수·백분율·순위를 노출하지 않고 공식 근거와 직접 확인할 한계를 보여준다.
7. 사진 표시가 승인되지 않은 경우 실제 교수 사진처럼 보이게 만들지 않는다.
8. 입력 변경, 늦은 응답, 비정상 응답, 장시간 요청이 이전 결과를 잘못 노출하지 않는다.

## 2. 입력 계약

### 전공 진화 실험실 — 만들다

| 입력 | 필수 여부 | 제한 | 용도 |
|---|---|---:|---|
| 아이디어 탐색 방식 | 필수 | 1개 | 자유 탐색 / 학과×AI / 전공 융합 |
| 학교 | 선택 | 80자 | 학교 맥락 표시와 교수 데이터 범위 확인 |
| 전공 계열 | 필수 | 10개 중 1개 | 임의 전공의 범용 아이디어 문맥 |
| 학과·전공 | 필수 | 80자 | 검색 추천 또는 직접 입력 |
| 관심 분야 | 필수 | 최대 3개, 항목당 60자 | 공통 태그 또는 직접 입력 |
| 관련 경험 | 필수 | 1개 | 시작 난이도와 설명 수준 |
| 방법·도구 | 필수 | 최대 2개 | 실행 가능한 방법 범위 |
| 준비 기간 | 필수 | 1개 | 4주 / 8주 / 한 학기 |
| 데이터 접근 | 필수 | 1개 | 공개 / 직접 수집 / 확인 필요 / 모름 |
| 피하고 싶은 방식 | 선택 | 복수 | 후보 제외 조건 |

기존 검수 전공은 준비된 후보를 사용하고, 그 밖의 전공은 사용자가 확인한 전공 계열·학과·관심·방법·기간·데이터 조건만 조합해 `안전 축소형`과 `차별 심화형` 두 후보를 만든다. 존재하지 않는 수업·교수·논문·데이터를 사실처럼 만들지 않는다.

AI 공동설계 API는 `majorArea`를 포함한 필수 배열과 문자열을 서버에서 다시 검증한다. 학교명은 아이디어 생성에 필수 근거가 아니므로 AI 프롬프트의 안전 입력에는 포함하지 않는다.

### 나의 교수님 — 찾다

| 입력 | 필수 여부 | 제한 | 용도 |
|---|---|---:|---|
| 학교 | 교수 연결 시 필수 | 단국대 별칭 정확 일치 | 공식 데이터 범위 확인 |
| 도움 목적 | 필수 | 1개 | 진로 / 주제 / 프로젝트 / 대학원 |
| 학과·전공 | 필수 | 80자 | 직접 입력 가능 |
| 관심 분야 | 필수 | 1~3개, 항목당 60자 | 태그 또는 직접 입력 |
| 구체 연구주제 | 선택 | 160자 | 주제 근거 구체화 |
| 진로 목표 | 선택 | 1개 | 취업 / 대학원 / 창업 / 탐색 |
| 만남 상황 | 선택 | 1개 | 수업 후 / 오피스아워 / 이메일 / 연구실 |
| 추가 맥락 | 선택 | 300자 | 경험·제약·원하는 도움 |

`단국대학교`, `단국대`, `Dankook University`, `Dankook`을 공백·대소문자 정규화 후 정확히 일치시킨다. `단국대아님`처럼 접두어만 비슷한 값은 API에서 422로 거절한다.

## 3. 교수 3관점 선택 규칙

정책 식별자는 `OFFICIAL_EVIDENCE_RULES_V3`다.

1. 단국대학교 공식 프로필 URL과 공식 연구분야 또는 공식 프로필 노출 논문 근거가 있는 후보만 사용한다.
2. 동일 교수를 중복하지 않는다.
3. `TOPIC → METHOD → CONTEXT` 역할을 한 자리씩 채운다.
4. 해당 역할과 직접 일치하는 공식 근거가 없으면 다른 공식 연구 근거가 있는 교수를 `LIMITED`로 제시한다.
5. `LIMITED` 카드는 직접 일치 근거가 확인되지 않았음을 이유와 확인 항목에 명시한다.
6. 모든 조건이 같으면 안정적인 교수 ID로 결과를 재현한다.
7. 면담 가능 여부, 지도·모집 여부, 참여 의사, 성공 가능성은 판단하지 않는다.

이 구조는 3명을 1~3등으로 세우는 추천이 아니다. 학생이 교수에게 접근할 때 필요한 `연구 내용`, `연구 방법`, `확장 맥락`의 서로 다른 대화 관점을 제공한다.

## 4. 교수 이미지 정책

Obsidian 사진 참조 장부에는 단국대학교 공식 페이지 기반 623건이 있고 런타임 교수 ID와 모두 일치한다. 그러나 현재 623건 전부 `REFERENCE_ONLY_PERMISSION_UNVERIFIED`로, 앱 화면 표시 승인이 확인된 사진은 0건이다.

따라서 현재 화면은 다음 규칙을 사용한다.

- 승인 사진이 없으면 주제·방법·확장·상세 역할별 브랜드 교수 일러스트를 표시한다.
- 화면에 `브랜드 일러스트`, 대체텍스트에 `실제 사진이 아님`을 명시한다.
- 외부 인용 사이트 이미지와 권리 미확인 URL은 사용하지 않는다.
- 원격 사진을 직접 핫링크하지 않는다.
- 향후 승인 사진은 `public/official-professor-photos/`에 최적화한 사본을 넣고, 교수 ID·이름·공식 프로필·출처 페이지·확인일을 승인 장부에 함께 등록한다.
- 승인 장부의 교수 이름이 현재 교수 이름과 다르면 실제 사진을 사용하지 않는다.

## 5. 요청 안정성과 오류 처리

- 교수 요청 제한 시간은 25초다.
- 입력을 바꾸거나 화면을 벗어나면 진행 중 요청을 취소한다.
- 이전 요청의 성공·오류가 늦게 도착해도 현재 요청과 다르면 저장하지 않는다.
- 입력 변경 즉시 이전 교수 결과를 숨기고 저장 상태를 초기화한다.
- 두 교수 연결 경로가 같은 HTTP 응답 검증기를 사용한다.
- 2xx 응답이어도 주제 ID, 교수 배열, 역할·강도, 교수 기본 필드, 범위 정보가 올바르지 않으면 오류로 처리한다.
- 비단국대 입력은 교수 API를 호출하지 않고 파일럿 범위를 안내한다.

## 8. 남은 위험과 다음 작업

1. 교수 데이터 범위는 `PARTIAL`이다. 단국대 공식 중앙 검색에도 소속 결과가 없는 전공 공백을 계속 표시해야 한다.
2. 개념 사전은 대표 분야 중심이다. 예술·체육·의료·인문 등 실제 입력 사례를 모아 공식 근거 회귀 케이스를 늘려야 한다.
3. 임의 전공의 로컬 대체안은 비교쌍 한 세트라 두 후보를 모두 제외한 뒤에는 추가 후보가 없다.
4. 신규 연구·교수 화면의 390px 실제 브라우저 재검증은 현재 브라우저 연결이 고정 데스크톱 뷰포트라 이번 실행에서 완료하지 못했다. PR 전에 390×844, 360px, 430px에서 직접 확인한다.
5. 승인 사진을 처음 추가할 때 로컬 이미지 파일 존재·크기·포맷을 확인하는 자동 검증 스크립트를 함께 추가한다.
6. 공개 배포 전 AI·교수 API 요청 제한, 비용 상한, 익명 사용량 보호가 필요하다.

## 9. 팀 검토 순서

1. `/research`에서 학교를 비우고 임의 전공과 직접 관심 분야를 입력한다.
2. 모든 필수 조건을 채워 `/co-design`으로 이동되는지 확인한다.
3. `/professors`에서 `단국대아님`을 입력해 파일럿 안내를 확인한다.
4. 단국대학교·목적·전공·관심 분야를 선택해 교수 3명을 실행한다.
5. 결과가 주제·방법·확장 한 명씩인지, 실제 사진 미사용 표기가 있는지 확인한다.
6. 검색 후 입력 하나를 바꿔 이전 결과가 즉시 사라지는지 확인한다.
7. 위 자동 검증 명령을 순서대로 실행한다.
