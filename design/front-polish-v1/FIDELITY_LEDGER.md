# Fidelity Ledger

| 점검점 | 시안 기준 | 구현 확인 | 조치·의도적 차이 |
|---|---|---|---|
| 첫 화면 위계 | 진행 → 제목 → 설명 → 장면 → 약속 → CTA | 모바일은 제목·설명·장면을 한 배경형 히어로로 합치고, 중복 튜토리얼 라벨 제거 | 이미지가 따로 뜨는 공간 낭비를 줄인 사용자 피드백 반영 |
| 타이포 | 데스크톱 큰 H1, 모바일 30px 안팎 | 데스크톱 38~48px 유동, 모바일 29~30px | 한국어 줄바꿈과 390px 폭에 맞춤 |
| 간격 | 8px 기본, 관련 요소는 좁고 그룹 사이는 넓게 | 4/8/12/16/24/32/48 토큰 적용 | 일괄 24px 반복 제거 |
| 색 | navy 본문, mint 신뢰, violet 한 개 주 행동 | CTA·진행만 보라, 신뢰 아이콘은 민트 | 그라데이션·glow 제거 |
| 반경·그림자 | 한 개의 soft-corner 가족, 기본 그림자 없음 | 8/12/16px, 카드 기본 그림자 없음 | pill은 상태 태그에만 유지 |
| 이미지 | 학생 맥락을 보조하는 안정 비율 | 일반 단계 16:9, 모바일 시작은 제한 높이 배경, 로봇·발광 경로 제거 | 시작 화면만 텍스트 오버레이로 공간을 압축하고 이후 질문은 표준 비율 유지 |
| 약속 목록 | 열린 행과 얇은 구분선 | 50~54px 행, 1px 구분선, 동일 outline 아이콘 | 비상호작용 행의 장식 화살표는 넣지 않음 |
| 모바일 CTA | 첫 화면에서 가리지 않고 명확히 노출 | 390×844에서 버튼과 안내 문구 노출 | 흐름 안에서 sticky로 동작 |
| 공통 허브 | 한 개의 주요 표면 + 열린 목록 | 교수 찾기 허브에 왼쪽 accent rail, 사각 아이콘, 열린 행 적용 | 여러 개의 동일 카드 생성 금지 |
| 접근성 | 48px 이상 터치 영역, 텍스트 대체 | 주 제어 52px, 이미지 alt, focus-visible 유지 | 색만으로 상태를 설명하지 않음 |
