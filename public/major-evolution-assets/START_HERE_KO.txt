전공진화 원본 픽셀 분리 에셋 - 교정 납품본

이 ZIP은 이전 파일의 문제를 수정한 버전입니다.

수정 사항
- ZIP 내부 파일명과 폴더명을 모두 영문/숫자 ASCII로 변경
- 중첩 ZIP 제거
- JSON 파일 0개
- 압축을 열자마자 PDF와 미리보기 JPG가 보이도록 구성
- PNG/JPG 원본 파일을 실제 폴더에 직접 포함
- AI 생성, 재그림, 얼굴 복원, 생성형 업스케일 0개

폴더 설명
01_SOURCE_SCREENS : 원본 화면 10개
02_EXACT_CROPS : 원본 화면에서 좌표대로 직접 자른 기준 PNG 53개
03_TRANSPARENT_PNG : RGB를 바꾸지 않고 알파만 추가한 선택적 PNG 16개
04_MARKED_CONTEXT : 분리 위치 표시 화면 10개
05_CONTACT_SHEETS : 화면별 에셋 미리보기 10개
06_CHECKS : 파일 목록, 해시, 검증 결과

중요
- 기준본은 02_EXACT_CROPS 폴더입니다.
- 작은 얼굴/왕관/방패/로봇은 원본 화면에 존재한 픽셀 크기 그대로입니다.
- 큰 크기로 인위적으로 늘리거나 새 디테일을 만들지 않았습니다.
